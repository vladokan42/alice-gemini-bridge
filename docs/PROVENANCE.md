# Происхождение и границы адаптации

## Оригинальные проекты

| Проект | Источник | Как используется |
| --- | --- | --- |
| Quasar Bridge | https://github.com/skrashevich/quasar-bridge | На новой установке скачивается последний стабильный релиз, фиксируется commit, применяется наш отдельный патч |
| OmniRoute | https://github.com/cheaper-inference/OmniRoute | Последний stable выбирается у автора; официальный Docker-образ `diegosouzapw/omniroute` проверяется по версии и закрепляется по digest |

**Этот репозиторий хранит интеграционный комплект, а не исходное дерево или
готовые бинарники этих сервисов.** Для Quasar сохраняется только разница
`patches/quasar-integration.patch`; исходники загружаются напрямую у автора.
В OmniRoute патчи не вносятся, настройки выполняются через его собственный UI.
Нет привязки новых установок к старому commit Quasar или старому образу OmniRoute.

Автор оригинального Quasar Bridge — Sergey Krashevich и участники проекта.

отдельно как `INTEGRATION-NOTICE`. Лицензии и авторство оригиналов не заменяются нашими.
OmniRoute сохраняет свои лицензию и условия; этот проект не перелицензирует его образ.

## История прежней адаптации

Первая публикация была отдельным очищенным экспортом на основе Quasar commit
`8c1438269232171464d80b8b8fa50795cbf8c177`; локальный кандидат экспорта —
`390f54a6b31d86df1e50fa5e71be74ebce6ed381`. Это **история**, не текущая
зависимость установщика. Старые сервисные файлы удалены из текущего дерева,
история Git не переписана. Личные конфиги, журналы и локальная история устройств
в публикацию не входят.

Точная новая сборка описывается commit нашего комплекта, выбранным релизом/commit
Quasar, SHA-256 патча и проверенного исходника (`upstream.json`), а серверная —
релизом и digest образа (`stack.json`). Не считай слово `latest` идентификатором
уже установленной версии. При несовместимости патча или тестов установка
останавливается до записи на колонку, без возврата к старому исходнику.

## Изменения этой адаптации

- Родное короткое подтверждение «Думаю», ограниченный кеш только этой фразы,
  переиспользование штатного native-плеера.
- Редактируемый системный prompt без личной конфигурации владельца.
- Обработка отменённых ответов и поздних аудиофрагментов.
- Исправленный пропуск mic `SpotterEnd`/`Close` с самостоятельным служебным ID:
  неизвестный ID не приравнивается к подтверждённому устаревшему запросу.
- Восстановлена проверка eligibility для повторного вопроса вместо безусловного
  `true` из экспортированной основы: ошибка/неполный/неизвестный JSON запрещает
  replay. Обычные ответы не получают дополнительного вызова классификатора.
- Публичный OmniRoute/Gemini-конфиг: вопросы по умолчанию идут через отдельный
  OmniRoute в LLM, базовые команды остаются у Яндекса; модель задаёт пользователь.
- Скрипты embedded start/supervisor/возврата с проверкой точного собственного
  mount и синтетическими тестами. Они не являются универсальным установщиком.
- Загрузчик оригинальных stable-релизов и установщик для обозначенных Linux/ARM64
  платформ: отдельный OmniRoute с зафиксированным digest, подключение к нему через
  `configure`, проверка ограниченного ключа, передача и проверка моста, первый
  запуск с независимым таймером восстановления и явной голосовой приёмкой.
- Документация, локальная сборка, CI и проверка публикуемого дерева.

Изменённые файлы upstream помечены уведомлением о модификации. Модуль Go
`quasarbridge` и имя бинарника сохранены, чтобы не переписывать рабочие импорты
и служебные пути только ради названия репозитория.

## Что намеренно не включено

Секреты, идентификаторы/адреса устройств, персональные prompts, boot snapshots,
firmware, сторонние голосовые модели, реальные Opus-записи, история разговоров,
постоянные настройки серверов, автопубликация бинарных релизов.

Старое экспериментальное прерывание длинной речи удалено; в текущем коде нет
пользовательского таймера этой пасхалки. Новые команды и инструменты не добавлялись.
