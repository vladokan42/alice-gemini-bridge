Задаёшь вопрос — **Gemini** отвечает **родным голосом Алисы**. Бытовые
команды остаются за Яндексом. Запросы к модели идут через
**[OmniRoute](https://github.com/cheaper-inference/OmniRoute)** — открытый
шлюз на сервере в твоей сети.

В этом контуре **не нужен ключ Google AI Studio**: доступ к Gemini
подключается через **Google CLI / OAuth в OmniRoute**. Колонка обращается
только к локальному шлюзу. Действуют лимиты, доступность моделей и условия
выбранного провайдера — CLI-доступ не означает отсутствие ограничений.

Это **комплект интеграции, не копия двух сервисов**. Он скачивает оригинальный
[Quasar Bridge](https://github.com/skrashevich/quasar-bridge) Сергея Красевича
и применяет наши изменения отдельным патчем. Авторство и Apache-2.0 сохранены:
[происхождение](docs/PROVENANCE.md) · [LICENSE](LICENSE) · [NOTICE](NOTICE).
Не связан с Яндексом и Google.

## Как это устроено

```
Микрофон → Яндекс ASR → мост на колонке
                           ├─ «Поставь будильник» → штатный Яндекс
                           └─ «Почему небо голубое?» → OmniRoute (CLI-доступ к Gemini) → Gemini
                                                                                           ↓
                                                                             Родной голос Алисы ← Яндекс TTS
```

1. **Распознавание:** микрофон колонки захватывает голос, Яндекс ASR
   распознаёт текст и отдаёт его локальному мосту на колонке (`127.0.0.1:18861`).
2. **Маршрутизация:** мост по правилам разделяет запросы:
   - Бытовые команды (будильники, таймеры, музыка, громкость, свет)
     уходят в штатный Яндекс.
   - Смысловые вопросы отправляются в локальный **OmniRoute**.
3. **Генерация через CLI:** OmniRoute отправляет запрос в **Gemini** через
   подключённый владельцем **Google CLI / OAuth-провайдер**. Ключ Google
   AI Studio установщик не спрашивает и чужие сессии не импортирует.
4. **Озвучка:** ответ модели возвращается в мост, мост запрашивает у Яндекса
   родной синтез речи (`nativeTtsGenerate`), и колонка воспроизводит ответ
   привычным голосом Алисы.

Перед ответом колонка произносит **«Думаю…»** — короткий аудиофрагмент
создаётся один раз и переиспользуется. Контекст короткого разговора
хранится только в оперативной памяти.

| Фраза | Куда уходит |
| --- | --- |
| «Почему небо голубое?» | OmniRoute → Gemini (CLI) → голос Алисы |
| «Поставь будильник на семь» | Штатный Яндекс |
| «Как работает будильник?» | Gemini — это вопрос, не команда |
| «Стоп» | Штатная остановка |

## Что понадобится

- **Колонка** с уже работающим root, SSH-ключом и проверенным ключом хоста.
  Архитектура ARM64, SysV init, стандартный `quasar.cfg`. Это не
  универсальная прошивка — нужна совпадающая структура firmware.
- **OmniRoute на сервере** с подключённым доступом к Gemini через CLI
  (Google-аккаунт / OAuth). Ключ Google AI Studio не нужен; доступность
  модели, ограничения и условия своего подключения проверь отдельно.
- **Серверная машина** (Debian 13, Ubuntu 24.04 или любой существующий
  сервер в локальной сети с OmniRoute), доступная по частному IP с колонки.
- **Ключ OmniRoute** для колонки (создай его самостоятельно в веб-интерфейсе
  OmniRoute). Нужен отдельный ключ только
  для генерации через выбранное комбо, без прав управления.

## Быстрый старт

Скачай репозиторий на сервере:

```sh
sudo apt-get install -y git
git clone https://github.com/vladokan42/alice-gemini-bridge.git
cd alice-gemini-bridge
```

Настрой SSH-алиас `alice-speaker` для root-доступа к колонке
([инструкция](docs/INSTALL.md#ssh)).

### Вариант А: OmniRoute уже запущен (рекомендуемый)

Если у тебя уже работает OmniRoute с подключённым Gemini (например, комбо `omni-alice-lite` или `alice-gemini`):

```sh
# 1. Настрой адрес OmniRoute, имя комбо и ключ доступа для колонки
sudo python3 scripts/install.py configure \
  --base-url http://<IP_СЕРВЕРА>:20128/v1 \
  --model omni-alice-lite

# 2. Установи мост на колонку
sudo python3 scripts/install.py speaker --ssh alice-speaker
```

### Вариант Б: Установка с нуля через скрипт

Если поднимаешь всё на чистом сервере:

```sh
sh ./install.sh --dry-run              # Посмотреть, что произойдёт
sudo sh ./install.sh --ssh alice-speaker
```

Мастер скачает **последний стабильный релиз OmniRoute из оригинального проекта**,
закрепит образ по digest и поднимет отдельный контейнер. Затем он сделает паузу:
в интерфейсе OmniRoute подключи свой CLI / OAuth-доступ, настрой комбо и создай
ограниченный ключ колонки. Мастер проверит ответ и запреты доступа, скачает
актуальный Quasar Bridge, применит интеграционный патч и перенесёт сборку на колонку.

### Откуда берутся сервисы

| Компонент | Оригинальный источник | Что остаётся здесь |
| --- | --- | --- |
| Quasar Bridge | [skrashevich/quasar-bridge](https://github.com/skrashevich/quasar-bridge/releases/latest) | Только [патч интеграции](patches/quasar-integration.patch), пример настроек и установочная оболочка |
| OmniRoute | [cheaper-inference/OmniRoute](https://github.com/cheaper-inference/OmniRoute/releases/latest), официальный образ `diegosouzapw/omniroute` | Загрузчик, проверка версии и настройки отдельной установки |

**Старые исходники сервисов и готовые бинарники в текущем дереве не хранятся.**
При каждой новой установке выбирается актуальный stable, но скачанные commit,
патч и образ фиксируются для конкретной установки. Метаданные — `upstream.json`
на колонке и `stack.json` на сервере. Работающие установки не обновляются в фоне.

Если новый Quasar несовместим с патчем, конфигурацией или тестами, установка
**останавливается до записи на колонку**. Скрытой подстановки старой копии нет.
Для осознанного повторения прежней сборки можно указать точные оригинальные теги
через `--bridge-version` и `--omniroute-version`; это не обходит проверки.

## Активация и подтверждение

**Установщик не перезагружает колонку сам.** После успешной установки:

```sh
sudo ssh alice-speaker reboot
# Дождись загрузки; задай вопрос голосом, проверь «Стоп» и штатную команду.
sudo python3 scripts/install.py confirm --ssh alice-speaker
```

С момента первой перезагрузки включается независимый **10-минутный таймер
возврата**. Если за 10 минут ты не подтвердишь работу командой `confirm`,
мост автоматически отключится, штатный маршрут восстановится, и колонка
перезагрузится в исходное состояние. Это страховка от потери управления,
не голосовая пасхалка.

## Настройки

- **Маршрут по умолчанию** — LLM. Бытовые команды перехватываются
  правилами `routing.rules` (регулярные выражения Go/RE2).
- **Характер** задаётся через `system_prompt`. В примере он нейтральный.
- **«Думаю»** — `voice_cues.enabled`. Кеш в `voice_cues.cache_dir`.
- **Инструменты и журнал** — выключены. Модель сама по себе не даёт
  поиск в интернете, погоду или управление устройствами.
